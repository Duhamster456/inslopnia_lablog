# Лабораторный журнал inslopnia

## Запуск

Скопируйте `.env.example` в `.env`. Задайте логин и пароль администратора и заполните `SECRET_KEY` случайным значением. Сгенерировать его можно командой `python -c "import secrets; print(secrets.token_hex(32))"`.

```sh
docker compose up --build -d --wait
```

Корень `http://localhost:8000/` отдаёт инструкцию по API в JSON для HTTP-клиентов и в HTML при обычном открытии в браузере. JSON можно явно запросить заголовком `Accept: application/json`.

Админка находится по адресу `http://localhost:8000/inslopnia_admin`. В админке добавьте пользователя, выдайте ему ключ и передайте значение ключа владельцу. Владелец может иметь несколько ключей. Отзыв ключа сохраняет записи и авторство. Новый ключ того же пользователя даёт доступ к редактированию его записей.

По умолчанию Compose публикует порт на `127.0.0.1`. `PORT` и `BIND_HOST` задаются в `.env`. При размещении за HTTPS включите `SESSION_COOKIE_SECURE=true` и направляйте запросы на этот порт через обратный прокси.

## Данные

Именованный том `journal` содержит `lablog.sqlite3` и каталог `entries/` с файлами записей. Первую строку каждого файла занимает заголовок, за ней следует текст записи. Для согласованной резервной копии остановите контейнер и скопируйте весь том. Обычный `docker compose down` сохраняет том.

Необязательное поле `url` содержит ссылку на файлы эксперимента по HTTP или HTTPS.
